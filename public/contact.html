Reporting a Bug or Validation Error

If you encounter an issue where valid JSON is flagged as invalid, or if formatting does not behave as expected, please include:

  • The operating system and browser version you are using (e.g., Chrome, Firefox, Safari, Edge).
  • A non-confidential sample of the JSON snippet that triggered the issue (ensure no personal passwords or tokens are included).
  • The indentation option selected (2-space, 4-space, tab, or minified).
  • A brief description of what was expected versus what occurred.
